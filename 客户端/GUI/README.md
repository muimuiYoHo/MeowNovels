# 喵小说客户端（Tauri 壳）

喵小说的 Windows 桌面客户端骨架。复用旧「喵番」Tauri 壳（标题栏 / 主题色 / 设置持久化 / 亚克力窗口），业务信息架构按 `../UI原型/` 对齐小说场景。

## 与旧喵番的关系

- 来源：约两年前的「喵番」桌面壳（原项目已难找回更早版本），本仓库在此基础上改成喵小说。
- 参考副本：`D:\work\喵番`（独立产品，勿与本目录混用）。
- 已完成：产品名 / 窗口标题 / 侧栏文案改为喵小说信息架构。
- 未完成：首页/收藏/资源等页面仍是壳内占位，业务功能要接 `../CLI工具` 与服务端接口。

## 运行

```bash
npm install
npm run tauri dev
# 或 windows开发板.bat
```

## 目录

- `src/` — Vue 前端（标题栏、控制台设置、首页占位）
- `src-tauri/` — Rust 命令（文件读写、系统主题色、窗口效果）
