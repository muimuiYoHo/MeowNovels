# 从 wenku8 下载轻小说喵~

v0.1
不使用浏览器从 wenku8.net 搜索并下载轻小说

## 使用方法

### 有 Node.js 环境的话 ~9.22MB：

```
使用「轻小说下载喵.bat」即可
那个exe就可以删除啦~
```

### 无 Node.js 的话 ~91.7MB：

```
使用「轻小说下载喵.exe」
其他东西就可以删除啦~
```

## 使用步骤

```
1. 首次使用可以先「设置登录信息」，输入你的 wenku8 账号（如果你不需要搜索功能请无视
2. 支持网页的「按书名/作者搜索」，一样请输入关键词
3-1. 模糊搜索下输入搜索结果序列号，然后确认下载
3-2. 精确匹配就直接确认下载
4. 下载的 txt 在「下载」文件夹里
```

## 自定义

编辑 `ui.json` 可以改界面上的所有文本，你喜欢就好~

## 需求

想要最小的工具体积(9.22MB)可以安装 Node.js 18+ 环境，然后：

```
npm install
```
安装依赖

## 注意

- 搜索功能需要登录 wenku8 账号
- 下载不需要登录（如果你知道轻小说id/详情页url
- 搜索每页间隔 5 秒，多页搜索结果要稍等
- 你的账号密码保存在旁边的 `wenku8配置.json`，别发给别人（我也不会偷你的
- 所有环境依赖都打包了所以体积大了点，你可以根据实际使用删除一些
