# AGENTS.md

wenku8 轻小说下载工具 - Node.js CLI 应用（喵小说命令行入口；GUI 壳见 `../客户端`）

## 运行

```bash
npm start          # 启动 CLI（= node src/gui.js）
```

启动器 `轻小说下载喵.bat` 内含 `chcp 65001`。

## 架构

ESM 模块，入口 `src/gui.js`：

- `gui.js` - CLI 界面、主菜单、用户交互
- `源注册.js` - 静态导入 `源/*.js` 并按 `id@版本` 去重
- `源/wenku8.js`、`源/esjzone.js` - 资源站实现，导出 `源`
- `工具/` - 网络.js、文件.js、文件写入.js、文件下载.js、下载进度.js、html解析.js、繁简转换.js、分页.js

新增资源站：在 `src/源/` 放文件后运行 `更新源.bat` 自动注册，不要手改 `源注册.js`。

## 关键细节

- 编码：wenku8 使用 GBK，用 `iconv-lite` 转换
- 搜索需登录，下载无需登录
- 搜索结果翻页间隔 5 秒（防封）
- UI 文本在 `src/ui.json`，外部 `ui.json` 优先于内嵌默认（省略键会回退内嵌默认）

## 后端对接（喵小说服务端）

- 模块：`src/工具/后端.js`——查询资源 / 上报上传 / 后端下载、语言编码推导
- 开启方式：`设置.json` 加 `"服务端地址": "http://<服务器IP>:3080"`，留空则纯本地模式
- 下载流程已接入：下载前先查后端，服务器已有 → 可选直接从服务器下载（跳过官方）；否则官方下载后自动上传（新增/更新）
- 分卷：每卷下载后逐卷上传，卷号 = wenku8 的 vid
- 接口约定见本仓库根目录 `接口文档.md`（部署说明见 `部署说明.md`；服务端源码不在本工作区）

## 配置文件

- `账号.json` - 账号密码（本地存储，勿提交）
- `设置.json` - 设置（含 `服务端地址`、`连通测试`）
- `下载/` - 下载存储目录（自动创建）

## 打包

不能直接 `npx pkg .`（node-fetch v3 的 `import.meta` 会让 pkg 闪退），必须先 esbuild 打成单文件 CJS 再 pkg，完整流程见 `打包说明.md`。

## 依赖

- `iconv-lite` - GBK/Big5 编码转换
- `node-fetch` - HTTP 请求
- `opencc-js` - 繁简转换
