# 喵小说服务端接口文档

服务端（Docker 部署）：`http://<服务器IP>:3080`
本地测试：`http://localhost:3080`

- 所有响应 JSON，结构 `{ 成功: true|false, ... }`
- 出错返回 `{ 成功: false, 错误: "原因" }`
- CORS 全开（`*`），支持 `OPTIONS` 预检
- 中文路径/参数一律 URL 编码（`encodeURIComponent`）
- 上传为**原始字节流**（`application/octet-stream`），非 multipart

---

## 1. 健康检查 — GET /健康

```
GET http://localhost:3080/健康
```

```json
{ "成功": true, "服务": "喵小说服务端", "时间": "2026/8/8" }
```

## 2. 查询资源 — POST /任务

```
POST http://localhost:3080/任务
Content-Type: application/json
```

请求体：

```json
{
  "行为": "查询",
  "来源": "wenku8",
  "外部id": "728340",
  "卷": "0",
  "全文": true,
  "编码": "utf8",
  "语言": "简",
  "外部更新时间": "2026/8/7",
  "全文长度": "123456"
}
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| 行为 | 是 | 固定 `"查询"` |
| 来源 | 是 | 资源站 id（`wenku8`/`esjzone`/`mm`…） |
| 外部id | 是 | 资源站的小说 id |
| 卷 | 否 | 卷号字符串；全文传 `"0"`（或省略 + `全文:true`） |
| 全文 | 否 | `true` = 全文，默认 false |
| 编码 | 否 | `utf8`/`gbk`/`big5`，仅影响返回的下载 url |
| 语言 | 否 | `简`/`繁`，影响下载 url |
| 外部更新时间 | 否 | 日期如 `2026/8/7`，用于过时判定 |
| 全文长度 | 否 | 数字字符串，用于过时判定 |

响应（成功）：

- **不存在**（库中没有或未开放）：

```json
{
  "成功": true,
  "状态": "不存在",
  "消息": "库中没有该资源或未开放",
  "下载方案": "官方"
}
```

- **最新**（可走后端直接下载，附下载 URL）：

```json
{
  "成功": true,
  "状态": "最新",
  "消息": "资源是最新的，可直接下载",
  "资源": {
    "Mui轻小说id": 3,
    "名称": "司命之上",
    "来源": "wenku8",
    "外部id": "728340",
    "卷": "0",
    "库": { "全文长度": "39", "外部更新时间": "2026/8/8", "本地更新时间": "2026/8/8", "sha256": "…" }
  },
  "下载": { "方式": "后端", "url": "/下载?行为=下载&muiid=3&来源=wenku8&外部id=728340&卷=0&编码=utf8&语言=简" }
}
```

- **过时**（更新时间和长度均落后 → 去官方下载后走「更新」上传）：

```json
{ "成功": true, "状态": "过时", "下载": { "方式": "官方" } }
```

- **需人工**（仅一项落后，上传 .mui 交人工）：

```json
{ "成功": true, "状态": "需人工", "下载": { "方式": "官方" } }
```

- **索引异常**（开放资源缺对应库记录，人工检查库存）：

```json
{ "成功": true, "状态": "索引异常", "消息": "开放资源缺少对应库记录，请人工处理" }
```

## 3. 报告 + 上传 — 先 POST /任务，再 POST /上传/{令牌}

### 3.1 报告（要上传动作前的第一步）

```
POST http://localhost:3080/任务
Content-Type: application/json
```

```json
{
  "行为": "新增",
  "来源": "wenku8",
  "外部id": "728340",
  "名称": "司命之上",
  "编码": "utf8",
  "全文": true,
  "卷": "0",
  "语言": "简",
  "外部更新时间": "2026/8/8",
  "全文长度": "123456",
  "sha256": "可选，服务器会核验"
}
```

行为取值：`新增` / `更新` / `异常`

- `新增`：库中不存在 → 官方下载 → 全文或分卷上传
- `更新`：库中已过时 → 官方下载 → 全文或分卷上传
- `异常`：上传 `.mui` 文件（不带资源信息，供人工查看），不自动处理

响应：

```json
{ "成功": true, "令牌": "a1b2c3d4e5f6", "上传地址": "/上传/a1b2c3d4e5f6" }
```

### 3.2 上传文件（POST /上传/{令牌}）

```
POST http://localhost:3080/上传/a1b2c3d4e5f6?文件名=司命之上.txt
Content-Type: application/octet-stream
<body = 文件原始字节流，不要用 multipart>
```

- 仅接受 `.txt` / `.mui`（其他 415）
- sha256 计算方式：报告里填了才核验，不匹配 400
- 落点：新增→`待处理/`，更新→`待更新/`，异常→`人工/`（文件名加 8 位日期前缀）
- 新增/更新在后台上自动处理：编码转 utf8 → 繁体转简体 → 入库/替换
- 分卷文件命名任意，后台按卷号归档

响应：

```json
{
  "成功": true,
  "消息": "资源已接收，行为=新增",
  "sha256": "619beef…",
  "处理行为": "新增",
  "临时文件": "/资源库/轻小说/待处理/20260808_司命之上.txt",
  "字节数": 39
}
```

错误示例：

```json
{ "成功": false, "错误": "报告不存在或已过期，请先报告再上传" }
{ "成功": false, "错误": "仅接受 txt / mui 格式" }
{ "成功": false, "错误": "sha256 与报告不一致" }
```

## 4. 下载 — GET /下载

```
GET /下载?行为=下载&muiid=3&编码=gbk&语言=繁
GET /下载?行为=下载&来源=wenku8&外部id=728340&卷=0&编码=gbk&语言=繁
```

定位方式二选一：

- **按 muiid（推荐）**：`muiid=<Mui轻小说id>`，仅凭 id 即可唯一定位，无需来源/卷
- 按来源（旧）：`来源` + `外部id` + `卷`（0=全文）

`编码`/`语言` 决定输出转换。存储为 utf8 简体，按请求运行时转换为 gbk/big5/繁体。

响应：200 + `text/plain`，`Content-Disposition: attachment; filename*=UTF-8''{文件名}`（如 `司命之上.txt`、`司命之上-第2卷.txt`）

错误：

```json
{ "成功": false, "错误": "资源不存在或未开放" }
{ "成功": false, "错误": "文件缺失或不可读" }
```

## 客户端对接流程（标准三段式）

```
① POST /任务        {行为:"查询", …}
   ├─ 状态=最新      → 直接 GET 返回的 下载.url，存盘（可跳过官方）
   ├─ 状态=不存在    → 官方下载 → ② → ③（新增）
   ├─ 状态=过时      → 官方下载 → ② → ③（更新）
   └─ 状态=需人工    → 官方下载 → ② → ③（异常，传 .mui）
② POST /任务        {行为:"新增"|"更新"|"异常", 元数据}
   得 令牌
③ POST /上传/{令牌}  原始字节流 ?文件名=xx.txt
```

约定：`全文长度` = 文件 utf8 字节数（`Buffer.byteLength`）；`外部更新时间` 用源的最后更新时间，格式 `YYYY/M/D`。
