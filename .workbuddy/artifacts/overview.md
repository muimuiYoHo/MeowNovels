# 喵小说 GUI · 双平台 UI 设计方案（交付概览）

## 交付内容

为 CLI 工具「喵小说（轻小说下载喵）」升级为图形界面应用设计双平台 UI 方案，交付 3 个可直接在浏览器打开的静态 HTML 原型：

| 文件 | 内容 | 平台 |
|---|---|---|
| `index.html` | 设计总览页：品牌令牌 / 平台策略 / 信息架构 / 双端入口 | — |
| `pc.html` | PC 端 6 页面完整原型 | Windows 11 Fluent Design |
| `android.html` | 安卓端 6 页面完整原型（含日志二级页） | Telegram Material 变体 |

## 关键设计决策

1. **品牌统一**：双端共用品牌主色 `#2E7CF6`、辅助色 `#FF9F43`、同一线性图标语言（2px 描边）与字号阶梯（28/20/16/14/12）；状态徽章语义一致（最新=绿 / 可下载=蓝 / 需人工=橙 / 过时=红），与「接口文档.md」的查询状态一一对应。
2. **PC 端（Fluent）**：Mica 半透明窗口（backdrop-filter 模拟）+ 8px 圆角卡片 + NavigationView 侧边导航 + Segoe UI Variable 排版；控件采用 Fluent 语义（accent 按钮、ToggleSwitch、滑块、chip）。
3. **安卓端（Telegram）**：标志性蓝气泡 + 消息气泡式搜索（用户发搜索请求→助手回结果气泡，内嵌资源卡）+ FAB + 底部 5 导航；设置页为分组列表，日志作为二级页从设置进入（带返回）。
4. **信息架构**：双端 6 页面同构（首页搜索 / 收藏 / 资源管理 / 历史记录 / 设置 / 日志），交互逻辑与功能布局一一对应，跨端零学习成本。
5. **功能贴合真实产品**：搜索（来源 wenku8/esjzone/mm、编码、简繁）、下载状态（最新/可下载/需人工/过时）、登录配置、搜索间隔 5s 等均取自 CLI 工具与接口文档。

## 说明

- 原型为静态交互演示：PC 端导航切换、安卓端底部导航/二级页/FAB 可交互。
- 本会话中 Ardot 画布连接器不可用，故以 HTML 静态原型作为最终交付物（即用户要求的「可直接在浏览器预览」形式）。
- 预览服务：`http://localhost:8787`（由 server.js 提供，可随时重启）。
