01平台策略

同源信息架构 · 分平台视觉语言 · 统一品牌基因

PC 端 · Windows 11 Fluent

遵循 Fluent Design 规范：Mica 材质半透明窗口、8px 圆角卡片、标准控件体系（NavigationView / ToggleSwitch / 进度条）、Segoe UI 系统级排版。

  • Mica 亚克力窗口背景
  • NavigationView 侧边导航
  • 圆角卡片 + 细腻层级阴影

安卓端 · Telegram 风格

借鉴 Telegram 简洁现代的 Material 变体：标志性品牌蓝、消息气泡式搜索结果、FAB 浮动操作按钮、分组列表与底部导航。

  • 搜索即对话 · 气泡式结果
  • FAB 浮动操作按钮
  • Material 分组列表 + 底部导航

跨端一致性策略

两端共享同一套信息架构、功能布局与交互逻辑；品牌色、图标语言、字体层级完全统一，用户换端零学习成本。

  • 6 页结构两端一一对应
  • 同一品牌色板与语义色
  • 同一线性图标语言（2px 描边）
  • 同一字号阶梯 28/20/16/14/12
