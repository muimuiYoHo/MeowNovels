## 未发布

### 新增 | New

- **书源系统**：源协议升级至「日喵 0.4」，宿主与源之间只有 `喵.工具` 一个接触面
  - `方法/源/元信息.js`：剥注释 → 平衡括号扫描 → JSON.parse 的静态提取（全程不执行源），校验必填字段、协议版本、能力白名单，报错带行号

  - `方法/源/管理.js`：加载 / 自动登录 / 搜索 / 详情 / 目录 / 封面，详情与目录走进程内 LRU，空壳一律不进缓存
  - `方法/源/工具/`：网络请求、编码处理、解析文本、繁简转换、凭据存取、翻页、封面、流量统计八个能力模块
- **内置书源**：文库8（按新协议重写）、源注册表、两个平台 logo
- **原生网络层**：`src-tauri/src/net.rs`（reqwest + rustls-tls + cookie jar，原始字节走 base64 回 IPC）
- **安卓网络桥**：`方法/网络.android.js` Rust / Kotlin 双后端、隐藏 WebView 过 Cloudflare 挑战、取页串行闸门、凭据与系统 CookieManager 双向同步
- **搜索页**：输入就搜、结果 LRU 缓存、分页按需加载、限速重试倒计时、挑战后台预热、历史记录分组
- **详情页**：按卷折叠目录（`grid-template-rows: 0fr ↔ 1fr`）、封面取回后落盘、字数压缩口径（w / m）
- **历史记录**：搜索为起点、行为只升不降、五档时间分组、封面按记录 id 落文件
- **开放空间**：SAF 授权目录与空间目录双形态，`写文本到` 统一写入入口
- **设置项**：书源 / Cookie / 资源目录 / 流量使用情况 / 模板
- **图片转 b64**：`FileReader` 原样编码，不重编码，保住 PNG 透明通道
- **图标**：新增 11 个 SVG（书、创建新文件夹、删除、小星星、开始、文件夹打开、文件夹管理、汽车故事关闭、网络检查、饼干、饼干大赛）
