# 打包说明

## 为什么不能直接用 pkg

`node-fetch` v3 是 ESM-only，pkg 的 Babel 解析器不支持 `import.meta`，直接打包会闪退。

```
SyntaxError: Cannot use import statement outside a module
```

## 方案

esbuild 先打包成单个 CJS 文件 → 再用 pkg 封装成 exe

```
src/gui.js → esbuild → dist/bundle.js → pkg → 轻小说下载喵.exe
```

## 步骤

```bash
# 1. 打包成单个 CJS（内含所有依赖）
npx esbuild src/gui.js --bundle --platform=node --format=cjs --outfile=dist/bundle.js

# 2. 创建 dist/package.json
{
  "name": "wenku8-downloader",
  "version": "1.0.0",
  "main": "bundle.js",
  "bin": "bundle.js",
  "pkg": {
    "targets": ["node18-win-x64"],
    "outputPath": "."
  }
}

# 3. 封装 exe
cd dist && npx pkg . --compress GZip
```

## 产出

- `dist/wenku8-downloader.exe` — 单文件，无需其他依赖
- 复制为 `轻小说下载喵.exe` 即可分发

## 注意

- ui.json 已内嵌到代码中，外部有则优先用外部
- 依赖降级：node-fetch v2（CJS）兼容 pkg，但当前用 esbuild 绕过了这个问题
- bundle.js 约 3MB，exe 约 38MB（含 Node.js 运行时）
